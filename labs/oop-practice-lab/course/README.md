# Course index

Work through the numbered directories in order. Within each directory, read its
README and complete the numbered Python files in order.

```text
00_getting_started
  -> 01_functions
  -> 02_control_flow_and_collections
  -> 03_errors_and_validation
  -> 04_classes_and_objects
  -> 05_python_object_tools
  -> 06_oop_fundamentals
  -> 07_oop_patterns
  -> 08_oop_architecture
```

Every `.py` lesson is standalone. Run commands from the `oop-practice-lab`
directory. You do not need to finish or import another lesson to run the current
one.

## Maintainer convention

- A topic directory owns one coherent subject and its local prerequisites.
- A lesson teaches one primary idea, includes one worked example, and ends with
  small checks.
- Put supporting practice immediately after the lesson it reinforces.
- Prefer `10_`, `20_`, and `30_` when expanding a topic so lessons can be
  inserted later without renaming everything.
- Record new lesson order and prerequisites in the topic README.
- Do not make an early lesson import a learner's solution from a later lesson.

# 01 — Functions

Prerequisite: topic 00.

1. `10_def_and_function_calls.py` — define and call a no-input function.
2. `20_parameters_and_arguments.py` — pass changing input into a function.
3. `30_return_values.py` — send a result back to the caller.
4. `40_function_patterns.py` — transform, combine, delegate, and decompose.

Lesson 40 repeats the most useful function shapes and ends with a bill-splitting
problem. Do not move on until you can identify the inputs and output of each
function without looking at its implementation.

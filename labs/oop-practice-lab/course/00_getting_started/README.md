# 00 — Getting started

Prerequisites: none.

1. `10_how_to_use_these_lessons.py` — run a file and read a failure.
2. `20_values_and_variables.py` — values, names, assignment, and basic types.
3. `30_expression_drills.py` — six tiny arithmetic, string, and boolean drills.

In lesson 30, predict each result before running it. The transfer challenge
combines several expressions but deliberately introduces no functions yet.

# 04 — Classes and objects

Prerequisite: topics 00–03.

1. `10_from_dictionary_to_class.py` — why objects combine state and behavior.
2. `20_class_practice.py` — build a small class from requirements.
3. `30_class_design_drills.py` — independent state, transitions, and invariants.

Lesson 30 deliberately repeats `__init__`, `self`, and state-changing methods
across several domains. This repetition should make the syntax automatic before
the denser OOP lessons.

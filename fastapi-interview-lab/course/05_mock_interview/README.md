# 05 — Mock interview

Prerequisite: topics 00–04.

1. `10_task_api.py` — implement a complete API prompt in 45 minutes.

First pass: work without a timer and use the earlier lessons when stuck. Before
editing, keep a clean copy of the starter. For the second pass, redo that copy
in 45 minutes while speaking your reasoning aloud. Do not add a database or
split modules during the timed pass unless the interviewer asks.

Evaluation priorities:

1. The HTTP contract is correct and consistent.
2. Inputs and error cases are validated.
3. State changes are simple and testable.
4. Names and explanations are clear.
5. Production tradeoffs are identified without overengineering the exercise.
